# Source policy and formula boundaries

## Primary formula source

The primary permitted source is **Függvénytáblázatok: Matematikai, fizikai, kémiai, biológiai összefüggések**, Oktatási Hivatal, 2024:

<https://downloads.lipovszky-matek-fizika.hu/downloads/tankonyvek/fuggvenytablazatok/OH-FGV912GY__teljes.pdf>

For mathematics, consult only the mathematical material on PDF pages **1–75**. The page limit refers to the PDF viewer page number, not a printed page label. Ignore the physics, chemistry, and biology sections.

## Formula discipline

1. Before using a named or nontrivial formula, look for it in the permitted mathematical part of the source.
2. State the formula in the solution only when it advances understanding. Identify the conditions under which it can be used.
3. If a requested shortcut is not given in the source, do **not** introduce it as an unexplained black box. Instead:
   - derive it from permitted definitions/formulas; or
   - choose a longer permitted route; or
   - say plainly that the result cannot responsibly be justified from the allowed table alone.
4. Standard algebraic transformations, definitions, direct arithmetic, and elementary geometric reasoning may be used and explained. Do not disguise an external theorem as “obvious.”
5. When the formula comes from the table, cite it lightly in prose, e.g. “A megadott függvénytáblázat számtani sorozatokra vonatkozó összefüggését használjuk.” Do not clutter every line with a formal citation.
6. If the student provides their own class material, it is valuable context for notation, level, examples, and requested homework. It does not override the formula-boundary rule unless the user explicitly changes that rule.

## Useful orientation within pages 1–75

This is only a navigation aid, not a replacement for consulting the actual source:

- 6–8: notation and symbols.
- 13–18: combinatorics and graphs.
- 19–24: complex numbers.
- 25–29: equations, inequalities, means.
- 31–35: sequences, arithmetic/geometric sequences, interest calculation.
- 36–41: coordinate geometry, vectors, lines and planes.
- 42–45: solid geometry and volumes.
- 46–49: trigonometry.
- 50–58: plane geometry and conics.
- 59–67: elementary functions, exponential/logarithmic functions, limits, derivatives, integrals.
- 68–75: probability and statistics.

## No external-formula substitution

Do not silently replace a permitted school-level derivation with a more advanced formula from memory, an online source, CAS output, or a programming library. External tools can independently check arithmetic and symbolic consequences; they cannot become an undisclosed source of formulas.
