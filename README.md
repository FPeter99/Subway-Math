# Subway Math — Matek Tutor Skill

Egy szigorú, mégis közvetlen és tanulást segítő matematika AI skill az OpenCode rendszerhez.

## Funkciók

- **100%-os belső ellenőrzés:** Mielőtt leírná a megoldást, a háttérben kiszámolja és leellenőrzi.
- **Részletes magyarázat:** Lépésről lépésre, érthetően tanít (akár metrózás közben is megérthető).
- **Hivatalos függvénytáblázat:** Kizárólag az Oktatási Hivatal által kiadott függvénytáblázat (OH-FGV912GY) megengedett képleteit használja.
- **Házi feladatok automatikus megoldása:** Hosszabb tananyagokból és feladatsorokból kikeresi és levezeti a *Kitűzött házi feladat* részeket.
- **Interaktív vizualizáció:** Függvényekhez, vektorokhoz és geometriai feladatokhoz HTML alapú vizualizációt készít.

## Telepítés és használat

Project-level skillként a `.opencode/skills/matek-tutor/` mappában található.

Használathoz az OpenCode-ban tegyél fel egy matek feladatot, vagy hivatkozz rá:
```text
használd a matek-tutor skillt
```
